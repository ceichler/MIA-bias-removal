# N-Gram distribution

Contains all the code required to compute ngram overlap distributions and using it to pick a set of non-members reducing this bias


#### alter_distribution
    Picking a subset of the non-members to eliminate the n-gram bias


### files_bff
    Computes ngram overlap distribution and results

#### bff
    Used to compute ngram overlap distribution.
    This is based on the big friendly filter, original repo: https://github.com/allenai/bff/
